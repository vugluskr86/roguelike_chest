# Формат редактора

Редактор экспортирует JSON версии `2`. В каждой комнате есть размер, стены,
враги, special-клетки и `rules` (`RoomRules`). Формат может также хранить
сценарий. Перед загрузкой JSON проверяется `validateEditableLevel()`, затем
нормализуется `normalizeEditableLevel()`.

Для первой комнаты можно задать `playerStart: { "x": number, "y": number }`.
Импорт отклонит старт за границей, в стене или полностью изолированный стенами.
Проверка основана только на постоянной геометрии: враги и временные special-объекты
не считаются стенами. Чистая функция `reachableCells(room, start)` доступна для
проверок в инструментах и CI.

Это позволяет создавать комнату босса или сценарий без ручного редактирования
кода: экспортировать карту, изменить данные, импортировать и запустить её из
редактора. Старые уровни без `version` и `rules` загружаются с правилами по
умолчанию.

Если JSON содержит поле `scenario`, редактор проверяет каждый шаг и сохраняет
его при экспорте. Кнопка `▶` запускает безопасный предпросмотр: загружается
первый шаг и его сообщение выводится в журнал; `⏹` восстанавливает редактируемую
карту. Встроенный реестр сценариев при этом не изменяется.

Кнопка `📜` открывает визуальный конструктор шагов. Карта, враги, специальные
клетки, старт игрока и правила берутся из текущей комнаты редактора; автор
задаёт для выбранного шага тексты RU/EN и условие `clear` либо `reach`. Кнопка
«Добавить шаг из комнаты» сохраняет очередной снимок поля, «Сохранить шаг»
заменяет выбранный шаг и запускает валидацию всего сценария. «Удалить шаг»
убирает выбранный снимок; последний обязательный шаг намеренно не удаляется,
чтобы не создать невалидный сценарий. После сохранения
сценарий прикрепляется к уровню и его можно проверить через `▶`.

«Расширенный JSON» оставлен только для диагностики и совместимости с уже
созданными файлами; для обычного создания и редактирования сценария он не
нужен. Typed-модель `scenario-editor.ts` не зависит от DOM и покрыта unit-тестом.
