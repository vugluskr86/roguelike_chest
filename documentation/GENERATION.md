# Параметры генерации

`src/generation-config.ts` содержит общие параметры процедурного этажа, которые
используются в рантайме и должны изменяться только вместе с тестами распределений.

| Параметр | Назначение |
| --- | --- |
| `floorSizes` | Кривая размера доски: верхняя граница этажа и её ширина/высота. |
| `conveyorRewardChance` | Вероятность еды, а не ловушки, в конце конвейерной ленты. |
| `lavaChance` | Вероятность лавы на сгенерированной комнате. |
| `portalChance` | Вероятность пары порталов. |
| `veinChance` | Вероятность жилы. |
| `foodPerColour` | Минимум и максимум еды каждого цвета клеток. |
| `scrolls` | Минимум и максимум свитков. |

Алгоритм- и биом-специфичные параметры редактора пока находятся в
`src/gen/params.js`. При следующем изменении конкретного алгоритма его параметры
нужно перенести в типизированный конфиг, не меняя распределение без тестового
baseline.

## Диагностика повторов

Запуск `npm run generation:report` генерирует 1 000 детерминированных комнат и
выводит JSON-отчёт: число уникальных планировок, долю повторов, распределение
биомов и число специальных клеток. Этот отчёт не входит в обычный `npm test` и
служит baseline перед изменением весов генератора.
