# Игровой интерфейс

```text
┌──────────────────────────────── Верхняя панель ────────────────────────────────┐
│ Ярус · биом · seed | золото | пепел | настройки                               │
├─────────────────────────────── Игровое поле ───────────────────────────────────┤
│ Стены, клетки событий, игрок, враги, двери, ключи, частицы и реплики          │
├────────────────────────────── Нижняя панель ───────────────────────────────────┤
│ Колесо форм | голод | статусы | активные временные эффекты | журнал            │
└───────────────────────────────────────────────────────────────────────────────┘
```

## Верхняя панель

| Значение | Значение для игрока |
| --- | --- |
| **Ярус** | Номер текущего этажа забега. С ним растут размер поля, бюджет врагов и сложность. |
| **Биом** | Набор визуального оформления, правил генерации и предпочитаемых врагов/объектов этажа. |
| **Seed** | Число, определяющее игровую случайность забега. Одинаковый seed и одинаковые действия дают одинаковый результат; нужен для replay и диагностики. |
| **Золото** | Ресурс текущего забега для магазина и части событий. Не является мета-валютой. |
| **Пепел** | Постоянная валюта между забегами для мета-улучшений. |
| **Шах** | Индикатор угрозы: текущая клетка игрока атакуется врагом. Это предупреждение, а не отдельный урон. |

## Поле

| Объект или подсветка | Значение |
| --- | --- |
| Шахматная фигура игрока | Текущая активная форма; определяет допустимые ходы и взятия. |
| Вражеская фигура | Противник. Красная штриховка по нажатию показывает его зону атаки. |
| Бирюзовая точка | Безопасная доступная клетка для перемещения. |
| Янтарная точка | Доступная клетка, на которой игрок окажется под атакой. |
| Багровая точка с крестом | Ход возможен по геометрии, но немедленно опасен для последней формы или ведёт к фатальному состоянию. |
| Стена | Непроходимая клетка, блокирует линии дальнобойных фигур. |
| Дверь | Переход между комнатами; цветная дверь требует ключ соответствующего цвета. |
| Ключ | Открывает двери того же цвета в пределах текущего яруса. |
| Ловушка, лёд, лава, портал, конвейер, плита и другие специальные клетки | Срабатывают при входе; их точное правило показывается tooltip и журналом. |
| Реплика над клеткой | Атмосферное или контекстное сообщение сущности; важный результат дополнительно остаётся в журнале. |

## Нижняя панель

| Значение | Значение |
| --- | --- |
| **Колесо форм** | Доступные формы игрока. Активный слот выделен; пустой слот нельзя выбрать; cooldown показывает временно недоступную форму. |
| **Голод** | Запас ходов. При нуле активная форма разрушается; босс-комната может временно заморозить расход по `RoomRules`. |
| **Зелёная/жёлтая/красная зона голода** | Зелёная — безопасный запас; жёлтая — предупреждение; красная — критический запас. Границы и расход задаются баланс-конфигом. |
| **Статусы** | Яд наносит деградацию по таймеру, оглушение пропускает ход, щит поглощает одно взятие, ускорение меняет доступные действия. Число показывает оставшиеся ходы или накопленные щиты. |
| **Временные эффекты** | Временные бонусы с числом оставшихся ходов или условием снятия. Например, «Сытость» замедляет расход голода, даёт броню и сбрасывается при потере формы. |
| **Журнал** | История действий, наград, опасностей и системных сообщений. Цвет сообщает приоритет: обычный, награда/важное, критическая опасность. |

## Сообщения и эффекты

| Канал | Назначение |
| --- | --- |
| Toast | Короткое подтверждение действия. Обычные сообщения идут через очередь; важные не ждут. |
| Журнал | Постоянная история результата; не требует немедленного прочтения. |
| Реплика | Текст на поле у сущности или клетки. |
| Подсказка | Контекстное обучение, не заменяющее обязательную информацию на HUD. |
| Модальное окно | Необратимый выбор, лут, событие, итог или важная сюжетная сцена. |
| Виньетка, тряска, переход, частицы, вспышка взятия | Только визуальная обратная связь: голод/яд/мат различаются цветом, взятие — вспышкой, дверь/портал/ярус — типом перехода. Эти эффекты не изменяют game state и отключаются настройкой анимаций. |

## Редактор

Панель редактора содержит инструменты поля, вкладки объектов и действия открытия,
экспорта, импорта, preview и переключения комнат. Кнопка `📜` открывает редактор
сценария: выбранный шаг получает снимок текущей комнаты; автор задаёт RU/EN
сообщения и условие `clear` (победить всех) или `reach` (дойти до координаты).
Полный формат и ограничения описаны в `documentation/EDITOR.md`.
