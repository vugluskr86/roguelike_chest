# Сценарии

Сценарий — декларативная последовательность карт. Данные находятся в
`src/scenarios.ts`, исполнитель — функции `startScenario(id)`,
`loadScenarioStep()` и `advanceScenario()`.

Каждый `Scenario` содержит `id`, локализованное вступление, шаги и сообщение
завершения. Шаг задаёт размер и мутации доски, старт игрока, врагов, сообщение,
условие (`clear` или `reach`), награду и `RoomRules`. Исполнитель не вызывает
`newFloor()`: переходы между шагами происходят после игрового действия.

`ashen-trial` — эталонный акт из трёх уровней. При добавлении контента сначала
создайте данные сценария, затем добавьте тест переходов и локализации.

Внешний JSON проверяется `validateScenario()`, а `startScenarioDefinition()`
запускает его без добавления в `SCENARIOS`. Это используется предпросмотром
редактора: контент можно проверить до внесения в встроенный реестр.
