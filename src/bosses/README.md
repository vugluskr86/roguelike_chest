# Босс-комнаты

`config.ts` — реестр боссов и кривая endless-комнат. `rooms.ts` — единственная
фабрика карт и правил комнаты. Параметры endless-комнаты сохраняются в
`S.specialRoom`, поэтому seed и реплей воспроизводят босса, сложность и награду.

| Босс            | Цель и контр-игра                                      |
| --------------- | ------------------------------------------------------ |
| Мучитель        | Снять фазы, прячась от диагоналей за колоннами.        |
| Спаянные ладьи  | Развести пару и не закончить взятие на линии выжившей. |
| Жернов/Кукловод | Контролировать коридор и разворачивать механизм.       |
| Красный Король  | Разорвать цепи, затем убрать свиту.                    |

У всех боссов отключены голод, случайный спавн предметов и межэтажные события;
сложность, музыка и сообщения задаются `RoomRules`.
